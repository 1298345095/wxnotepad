# 保留编辑行为，分阶段迁移并选择性跟进上游

项目的最终目标是尽可能保留 Notepad4 的编辑功能与使用习惯。编辑行为兼容覆盖编码处理、搜索替换、语法高亮、折叠、补全、快捷键等；文件关联、右键菜单、配置存储等系统功能采用各平台对应方式，菜单、对话框和字体渲染允许原生差异。具体功能清单仍需核对，不把此目标解释为已经证明所有功能都能等价迁移。

首发面向 Windows 和 Linux，macOS 后续推进。验证基线为 Windows 10/11 x64、Ubuntu 24.04 及以后版本 x64，Linux 同时验证 Wayland 与 X11。迁移范围聚焦 Notepad4 编辑器，不包含独立文件浏览器 matepath；打开所在文件夹等功能调用系统文件管理器。

首个正式可用版本的 Windows 发行物为 ZIP 便携包，Linux 优先提供 Ubuntu .deb 安装包，由包管理器安装依赖；Linux 便携发行包后续补充。原型阶段提供简单的构建与运行入口，发行打包在后续实现阶段完成。此取舍不改变编辑器支持便携配置模式的决定。

接受分阶段交付：先跑通打开、编辑、保存、编码和搜索替换，再逐步补齐高级编辑能力；暂缺功能需明确记录。轻量级优先衡量启动速度和运行内存，同时测量发行包体积与大文件操作表现；先采集原版基线，再确定预算，当前没有已确认的数值阈值。基准覆盖小文件启动、10 MB/100 MB 文件编辑与搜索替换；1 GB 文件和超长单行作为压力测试，尚不作为首版硬性验收门槛。

后续选择性吸收 Notepad4 上游的编辑功能、语言支持及缺陷修复，不要求逐次完整同步。这使项目能够按跨平台需求演进，同时承担筛选和适配上游变更的维护工作。
