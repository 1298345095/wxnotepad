# 优先验证 wxWidgets 作为跨平台界面框架

项目希望将 Notepad4 的使用体验带到其他平台，并尽可能保留现有功能与轻量级特点。wxWidgets 是首选候选方案：用户认为 Qt 偏重，但尚未用本项目的构建和运行数据验证两者的资源开销；因此目前不将 wxWidgets 视为不可更改的约束。

是否正式采用 wxWidgets，取决于后续明确的功能保留要求、轻量级指标和原型验证结果。现有 Notepad4 使用定制 Scintilla，且 Windows 依赖涉及界面、文件处理及编辑核心；采用 wxWidgets 自带的 wxStyledTextCtrl 或移植现有编辑核心仍是待决事项。

## 已确认的验证路线

先用 wxStyledTextCtrl 制作最小原型，以现有 Notepad4 为行为对照，检查编码处理、正则搜索替换、中文输入、语法高亮及性能。发现行为差异后，评估迁移必要定制的成本；如果关键行为难以补齐，再评估接入原版定制 Scintilla 内核。

用户接受为编辑行为兼容维护必要的内核补丁及其长期维护成本，但尚未决定整体移植原版内核。验证路线已确认，最终框架与内核选型仍待原型结果，因此本 ADR 保持 proposed 状态。

## 原型边界与留存

原型回答的问题是：wxStyledTextCtrl 能否在可接受的资源开销和定制成本下，保留 Notepad4 的关键编辑行为？验证需要真实的 wxWidgets 程序，以观察原生输入法、编码、渲染及资源开销。

原型是可丢弃的技术实验：只实现回答问题需要的操作，提供简单的运行入口，显示或记录相关状态。保留对照样本、复现步骤和必要的测量脚本，不建设正式测试体系、通用抽象或完整错误处理；文件读写只针对明确标记的可丢弃样本，其他状态默认保存在内存中。正式交互完善、配置迁移和发行打包留到实现阶段。

代码、样本和测量脚本保存在 main 之外的 codex/prototype-* 分支中；每张实验票记录实际分支、提交和结论，后续实现票引用这些证据。main 保留确认后的决策，后续正式实现依据结论另行编写。已证实的不兼容也是有效实验结果；环境缺失或证据不足须记为待验证，不能据此判定路线通过。
